## 👨‍💻 프로젝트 소개



🎇 **Slogan - 자기계발을 효율적으로 하고 싶은 개발자를 위해**




<br/>

**❓ 기획 배경**

<img width="1000" alt="image" src="https://github.com/user-attachments/assets/fb412da1-3544-4bb9-abb5-89bb407ead56" />

* 자격증, CS 기타 다른 분야를 학습하는 과정에서 문제풀이가 필요한 경우 문제를 풀기 위해 문제은행 사이트에 방문해야 한다.
  * 개발자들이 자격증, CS 기타 다른 분야를 학습할 때 일일이 다른 사이트를 방문하여 진행해야 한다.
* 카테고리별 내가 관심있는 문제 및 기존에 풀이했던 문제들을 조회할 수 있는 곳이 있으면 좋을 것 같다고 생각했다.
* 언제든지 공부하고 싶은 분야에 대한 문제집을 만들어 서로 공유함으로써 동기부여를 유도하며 도움을 주고 받을 수 있는 온라인 스터디 공유 서비스를 기획하게 되었다.

<br/>

**☝️ 해결 컨셉 : 자유롭게, 기분좋게, 재미있게**

<img width="1000" alt="image" src="https://github.com/user-attachments/assets/5f4117df-73b6-402e-9252-8fd18d17f4a5" />
</br>

1) 내가 학습하고 싶은 분야의 문제들을 문제 카드로 생성하여 사용자가 문제집, 문제를 생성한다.
2) 사용자는 관심주제에 대한 문제를 선택하여 문제풀이를 진행할 수 있다.
3) Github Commit 내역 확인 기능과 유사한 기능을 통해 서로의 학습 내역을 공유하고 확인할 수 있다.
4) 사용자는 댓글을 활용하여 문제집과 문제, 문제풀이에 대한 의견을 작성할 수 있다.

<br/>

**✴️ 차별화**

<img width="800" alt="image" src="https://github.com/user-attachments/assets/ad639e51-ea46-4360-b3e3-64b3ee59b7d0" />
</br>

<img width="800" alt="image" src="https://github.com/user-attachments/assets/2cf2ac85-8ba0-4958-9f06-b5850c1de89d" />
</br>

1) DoDream은 문제집, 스터디 카드를 생성하여 서로의 관심 주제에 대한 문제와 스터디를 공유할 수 있다.
2) Github에 커밋이나 푸쉬 내역이 등록되는 것과 유사하게 일일 학습 내역을 다른 사용자와 공유함으로써 서로의 학습 현황을 확인할 수 있다. 

<br/>

**🥅 목표: 기대 효과(USER)**
1) 여러 사이트를 접속하지 않아도 내가 원하는 학습 정보를 **한 곳**에서 확인할 수 있다.
2) 사용자들은 학습내용 공유를 통해 서로의 학습 현황을 확인함으로써 **학습에 대한 동기부여**에 도움이 될 수 있다.
3) 사용자는 **자기가 원하는 스터디 모임을 생성 또는 선택**하여 특정한 시간에 체계적으로 스터디를 진행할 수 있다.
